# Architecture decision records

A decision is written here when it is made or reversed (AGENTS.md: definition
of done, item 6). The architect agent drafts an ADR; the human accepts it;
the doc-writer files the accepted draft.

- Name: `NNNN-kebab-title.md`, numbered from `0001`.
- Sections: **Context / Decision / Consequences / Status**.
- Status is `accepted`, or `superseded by NNNN` — a reversal writes a new
  ADR that names the one it replaces. Never contradict an accepted ADR
  silently.
